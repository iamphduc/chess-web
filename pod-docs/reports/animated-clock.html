1. At a glance

Goal. Make the running player's clock visibly tick. Replace the still BsClockHistory icon with a small clock face whose hand steps forward once a second, chess.com style, add low-time warnings, and fix the countdown so it can't drift.

What shipped. A pure, drift-free clock module (clock.ts), a new PlayerClock pill with an inline SVG face whose hand jumps a quarter turn per second in step with the digits, a red pill under 20 s, tenths under 10 s, a still hand for reduced-motion users, role="timer" plus one "10 seconds left" alert, and six --clock-* color tokens. No new runtime dependency.

3. Key decisions

chess.com-style look human

Decision
"I prefer the chess.com style." Based on draft direction A, keeping the app's pills, Quicksand, and Reset red #D9534F for low time.
Alternatives
Draft directions A "Quartz tick", B "Flag fall", C "Sixty beads"; none picked as-is.
Consequence
Hand color and the red-under-20s pill are marked (reading): an interpretation, not a verified copy.
Links
Plan → Look · look-directions.html

Quarter-turn tick, not a sweep human

Decision
Four hand positions; 90° jump per second, full turn every 4 s; no transition, no bounce.
Why
The human's memory of chess.com; easier to see at icon size than 6° steps. Ticking matches a countdown and distracts less (WCAG 2.2.2 notes).
Alternatives
Smooth spin, pulse, 60-step dial.
Links
Plan → Look, Key decisions

Drift-free countdown now plan interview

Decision
Remaining = remainingAtTurnStart − (Date.now() − turnStartedAt); the timer only triggers re-renders.
Why
A ticking icon makes drift visible, and tenths need exact time (research: OpenReplay, dev.to).
Alternatives
Keep subtracting 1 per setInterval; defer the fix.
Consequence
A background tab may make the hand jump several steps on return; digits stay right (accepted risk).

Hand driven by the digit tick agent

Decision
handAngle uses the same floored whole seconds as formatClock; angle goes inline on each render.
Why
Hand and digits can't fall out of step.
Alternatives
Research leaned the other way: "an independent CSS loop plus a Date.now() based clock fits a small app."
Consequence
One re-render per second (100 ms under 10 s), on the running side only.

Reduced motion via OS only; one 10 s alert agent default

Decision
prefers-reduced-motion holds the hand; role="timer" stays silent except a role="alert" sibling reading "10 seconds left".
Why
WCAG treats real-time games as essential motion; an in-app toggle needs a settings UI the app lacks. MDN's timer-role pattern.
Alternatives
In-app on/off setting; announcing every tick; silence.

Clock digits round down agent default — override anytime

Decision
Keep flooring: 09:59 about 1 ms after Play, 0.0 for the last 100 ms.
Why
Contract asked for it, so red starts exactly at 00:19 and hand and digits change together.
Alternatives
Round up (old clock showed 10:00 for the first second).
Who / links
Raised by the reviewer on #43; recorded by the orchestrator. decisions.md 2026-10-05 "Clock digits round down".

Real Quicksand 700 for existing bold text agent default — override anytime

Decision
Loading weight 700 for the digits makes sidebar headings and square labels use real bold; keep it.
Alternatives
Set those rules to font-weight: 500.
Who / links
Raised by engineer L1. decisions.md 2026-10-05 "Existing bold Quicksand text uses the real 700 weight".

No font self-hosting; keep react-icons orchestrator / sprint

Decision
Quicksand stays on the Google Fonts @import (now wght@500;700). react-icons stays in package.json though nothing imports it.
Why
Self-hosting wasn't in the plan and needed a download mid-build; removing a package changes the lockfile, outside the plan.
Consequence
One Someday queue entry: npm uninstall react-icons.
