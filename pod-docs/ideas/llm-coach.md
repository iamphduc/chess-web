# Idea: an LLM coach that explains moves

Status: parked

_Noted: 2026-10-03 · From: the roadmap (the computer opponent's open question)_

## The idea

The engine picks the move, and an LLM explains it in plain words, like a coach's comment. The LLM never picks moves itself, because LLMs often suggest illegal or weak moves.

## Why it's on hold

The API key can't live in a static site, so the LLM call needs a server.

## What would make it worth building

A server exists, for example the PartyKit server from [online play](online-play.md).
