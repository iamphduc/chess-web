# Idea: dark mode

Status: parked

_Noted: 2026-10-19 · From: the `ui-refresh` plan interview (left out of scope) · Plan: [ui-refresh](../plans/ui-refresh.md)_

## The idea

A dark version of the scorebook look, chosen by a switch or by the system setting (`prefers-color-scheme`). It uses the same layout and Quicksand font, with dark tokens for the page, cards, lines and text, and a board and grade colors that still read well.

## Why it's on hold

The `ui-refresh` plan ships one light look first, so every screen is consistent before a second theme doubles the colors to check.
